# DigiTest Login (React)

A simple, polished login UI implementing the **Corporate Navy** theme.

## Demo credentials

This app uses a **client-side** credential check (no backend calls yet):

- Username: `demo`
- Password: `pass123`

Use the **Autofill** button on the login card to quickly populate the sample credentials.

To change the demo credentials, edit:

- `src/components/LoginCard.jsx` (`SAMPLE_USERNAME`, `SAMPLE_PASSWORD`)

## Getting Started

In the project directory, you can run:

### `npm start`

Runs the app in development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Runs the unit tests.

### `npm run build`

Builds the app for production.
